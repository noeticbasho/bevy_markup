## Symptoms

```html
<p><a href="next.html"><img src="icon.png"></a> text</p>
```

Clicking the image emitted nothing: its span had no bindings. The text
runs of the same link worked.

## Root cause

`text_spec` built image spans with `link: None` (since `17aa2d4`, which
made links clickable for text spans only). Separately, Bevy 0.20's UI
picking backend hit-tests a text node's runs (`pick_ui_text_section` over
`run_geometry`) and never `TextLayoutInfo::inline_boxes`, so a pointer
over an inline image hits the text block (UPSTREAM U34).

## Fix

Image spans take the run's link like text spans (`link:
run.extras.link.clone()`), so `spawn_spans` gives them the link's
`ElementSignals`, element and `DomNode`. Open: a picking backend that
hit-tests `inline_boxes` (or Bevy doing so) for the click itself.
