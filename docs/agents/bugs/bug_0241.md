## Symptoms

Accepted with 320,010 modeled steps (under 1% of the limit), this
rendered for 2.02 s in release. Doubling n from 10,000 to 20,000 to
40,000 gave approximately 123 ms, 498 ms, 2.02 s. Outer loops can
multiply that work while printing nothing.

## Minimal reproduction

```jinja
{% set x = range(end=40000) | unique %}{{ x | length }}
```

## Root cause

Tera's `unique` calls `Vec::contains` on all previous distinct items.
The checker grouped it with linear filters and charged only byte work.

## Fix

Charge worst-case pairwise comparisons and element scan cost before
returning the unchanged value bound. Refuse context-sized input with
`AppSquared`, because its cost would grow quadratically in app data.
Small literal inputs remain accepted. See ADR 0047 and UPSTREAM U46;
no upstream changes or dependency upgrades are required.

## Validation

The new review_0009 regressions pass with the fixes. With the fixes
removed (for FTL, retaining the new error type but disabling enforcement),
all eight new regression tests failed, including the real-loader and
focus/activation tests. Full CI and a 15-minute honggfuzz campaign are
run after committing the fixes, at the user's request; their results
are reported by the fix session, not assumed here.
