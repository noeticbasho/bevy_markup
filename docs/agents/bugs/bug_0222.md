## Symptoms

Frame 0 of a step, margin 0: `p55` at y 93 in the windowed build, 96 in
the full build. The 3 px is `.sec { gap: 3px }`, the gap of the
sections holding the rows: one row gap missing above `p55`, the shape of
bug_0151 (coalesced spacers dropped their gaps) in some other path.

## Reproduction

Add to `tests/windowing_model.proptest-regressions`:

```
cc 2cefd636eb46204c99fb0b5d1d75b37e7f6069226173dd84e91f2150bf22d631 # shrinks to seed = 17702137485556457484
```

and run `cargo test --test windowing_model -- windowed_builds_match`.
The document nests `section.sec` (gap 3 px) with a `box` section, a
`{% if f %}` row and a 400 px row; steps: `f = false; scroll 820; f =
false; v = 71 chars; scroll 572; f = false; scroll 5341; scroll 6114; v =
5 chars; scroll 6094`. Not bug_0170 (whose exemption covers coverage in
frame 0 of a content step, not placement) or bug_0203 (no inline images).
