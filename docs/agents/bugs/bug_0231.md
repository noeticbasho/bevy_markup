# bug_0231 — The SVG `<style>` charge assumes cheap selectors, and refuses only after the matching ran

| field | value |
|---|---|
| ID | bug_0231 |
| Status | **fixed** (the commit after `4af00b9`) |
| Severity | medium (DoS: a refused 737 KB SVG takes 13.6 s to refuse) |
| Component | `src/svg_bounds.rs` (bug_0207's rule × element charge); upstream simplecss parse (U42) |
| Discovered by | [review_0008](../reviews/review_0008.md) L09 (a probe) |
| Discovery agent | Claude Code session, `claude-fable-5-2` |
| Commit at discovery | `54bad82` |
| Date | 2026-11-12 |
| Regression coverage | `style_sheets_are_charged_before_they_run` (2 000 class-heavy rules and a 40 000-rule sheet refused before they parse or match) |

## Symptoms

Release build, `svg::parse`:

| rules × elements | document | result |
|---|---|---|
| 5 000 × 6 000, type selectors | 71 KB | loads, 299 ms |
| 30 000 × 1 000, type selectors | 315 KB | refused (`TooLarge`) after 3.25 s |
| 2 000 rules of 16 classes × 16 000 elements with 16 classes | 737 KB | refused (`TooLarge`) after 13.6 s |

The last is 3.2 × 10⁷ pairs, just under the early check, at about
400 ns a pair where the charge assumes 15.

## Root cause

bug_0207 charges rules × elements ÷ 4 and refuses early only when that
alone passes `MAX_SVG_WORK`. Below that, the matching runs and the total
is checked afterwards. The charge per pair is constant, but a rule's
cost per element grows with its selector's parts and classes.

## Fix

Each rule's matcher call is weighed by its tests: 1 + 2 per class,
id, attribute or pseudo-class test, plus a call per 64 bytes of the
longest attribute value a class or attribute test reads; and the whole
charge is made before any matching. Probing found a second cost the
review attributed to matching: simplecss's parse is quadratic in the
sheet's length (UPSTREAM U42: every declaration raises and drops an
error whose position counts lines from the start), 0.55 s for 30 000
rules before any matching. `style_scan_bytes` sums the offsets of the
places those errors arise and charges them before simplecss parses.
