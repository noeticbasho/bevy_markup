## Symptoms

```
panicked at src/cascade.rs:1911:37:
start byte index 1 is not a char boundary; it is inside '�' (bytes 0..3 of string)
```

## Minimal reproduction

The stylesheet `:not\0(){` (8 bytes). lightningcss serializes the
selector with the NUL as U+FFFD, so `Compound::parse` sees `:not�()`.

## Root cause

After matching the name, the arm sliced `after[1..close]`, assuming
`after` started with `(`. Here it started with a 3-byte U+FFFD, and the
slice split it. With an ASCII character in that spot the slice didn't
panic but misread the selector: `:not.a)` matched as `:not(a)`.

The code has been there since the structural pseudo-classes landed
(2026-10-15). The nightly css fuzzer could have found it, but every
night since 2026-10-16 it stopped early on bug_0179's timeouts.

## Fix

The argument must open right after the name (`strip_prefix('(')`);
anything else fails the compound, and the rule is skipped like any
unsupported selector.
