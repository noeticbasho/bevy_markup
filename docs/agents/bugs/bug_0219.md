## Symptoms

- `sync_canvases`' `warned` and `unregistered` `Local` sets never drop
  despawned entities or old names: an app that spawns and despawns
  canvases (or names) keeps growing them.
- The "canvas inside text" warning compares the raw tag name, so
  `<CANVAS>` in a paragraph skips it (`build.rs:6994`). It still shows
  nothing (bug_0202); only the log line is missing.

## Root cause

The sets are only inserted into. The tag check is case-sensitive where
HTML tag names aren't.

## Fix (proposed)

Retain only live entities / registered names each run; compare the tag
ASCII-case-insensitively (or use the walk's lowered name).
