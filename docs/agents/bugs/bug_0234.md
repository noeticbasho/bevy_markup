## Symptoms

A canvas with `border-radius: 50px; border-width: 4px; overflow:
hidden`: the element resolves 50 px corners, while both pictures (image
and viewport) resolve `Vec2(0.0, 0.0)` on all four. The `canvas`
example's `.portrait` (`border-radius: 8px`, 3 px border) is affected;
how visible it is there isn't confirmed by a screenshot.

## Root cause

Bevy rounds a `ViewportNode` and an `ImageNode` by their own node's
radius (`bevy_ui_render` `lib.rs:1461`). The picture's node declares
none, and Bevy's overflow clip is rectangular. At `f76b320` the source
sat on the element, which had the radius.

## Fix

The picture's `Node::border_radius` is the element's padding-box
corners, as CSS has them: each resolved outer radius less the borders
beside it, at least 0, in logical px (`canvas::inner_radius`), updated
when it changes. (Bevy's `ComputedNode::inner_radius` only clamps; it
doesn't subtract the border.)
