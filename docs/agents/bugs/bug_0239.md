## Symptoms

The actual loader accepted this template and displayed `33554432`,
a 32 MiB intermediate string beyond the 16 MiB value limit. At 50
iterations the old check still passed; rendering that variant would
attempt a 1 PiB string (inference, not rendered). Tiny final HTML avoids
the output writer cap.

## Minimal reproduction

```jinja
{% set_global s = 'x' %}{% for i in range(end=25) %}
{% set_global s = s ~ s %}{% continue %}{% set_global s = '' %}
{% endfor %}<p>{{ s | length }}</p>
```

## Root cause

`nodes_in` treated `break`/`continue` as zero output and kept mutating
the abstract environment. An unreachable reset erased the carried
symbol before `growth` inspected the final state.

## Fix

A collector per loop preserves environments at both kinds of exit,
including exits inside branches and included/captured bodies. `loop_nodes`
joins the exits with fallthrough in both the symbolic growth pass and
the bounded iteration pass. Nested loops own their collectors. Traversal
continues conservatively for output/work, so unreachable code may still
cause a refusal. Copies/joins are charged to the analysis-work budget.

## Validation

The new review_0009 regressions pass with the fixes. With the fixes
removed (for FTL, retaining the new error type but disabling enforcement),
all eight new regression tests failed, including the real-loader and
focus/activation tests. Full CI and a 15-minute honggfuzz campaign are
run after committing the fixes, at the user's request; their results
are reported by the fix session, not assumed here.
