## Symptoms

- `tests/source_lint.rs` reads `src/*.rs` with a flat `read_dir`
  (lines 15 and 52), so `src/cascade/selector.rs` is never linted: a
  debug print or a file write there passes (review_0004 H05's class).
- SVG text is unfuzzed: `fuzzing` implies `svg`, not `svg-text`, and
  `fuzz::svg` draws with `SvgFonts::default()` (no fonts: text draws
  nothing). bug_0204 is a one-token variant of bug_0200's document,
  which the property test found on its first run.
- Related gaps that go with their fixes: no `stroke-dasharray` in
  `hostile_magnitudes_never_panic` or the calibration (bug_0205); no
  inline image laid out at a scale factor other than 1 (bug_0214).

## Fix proposed by the review

Walk `src/` recursively in `source_lint`. Fuzz SVG text: a fuzz build
with `svg-text` and a font (Bevy's embedded default) in the harness.

## Fix

`tests/source_lint.rs` walks `src/` recursively (`library_sources`,
which asserts it reaches `cascade/selector.rs`). `fuzzing` implies
`svg-text`, and `fuzz::svg` draws with `SvgFonts::default_font()` —
Bevy's default font, every family falling back to it — so the fuzzer
reaches text's outlines and paints.
