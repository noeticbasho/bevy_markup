## Symptoms

On the real picking stack: a `data-on-click` button with a `position:
absolute; pointer-events: none` canvas over it. Before a source is
registered, a click gives `["hit"]`; with the canvas showing an image,
`[]`. The picture child has no `Pickable`. At `f76b320` the source was
on the element itself, which ignored the pointer. A decorative 3D view
over a HUD is the case that breaks.

## Root cause

CSS `pointer-events: none` puts `Pickable::IGNORE` on the element. The
`CanvasPicture` child that `bind` spawns has no `Pickable`, and every UI
node without one blocks the pointer.

## Fix

`sync_canvases` reads the element's `Pickable` and `bind` keeps the
picture's in step every frame (inserted on spawn, replaced or removed
when a restyle changes the element's).
